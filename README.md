## 开始学习

以下命令适用于已安装 Python 3 和 Python Launcher 的 Windows PowerShell。

### 1. 检查 Python

```powershell
py -3 --version
```

若系统没有 `py` 命令，可使用 `python --version` 检查，并确认输出为 Python 3；后续命令中的 `py -3` 也相应替换为 `python`。

### 2. 创建虚拟环境

在仓库根目录执行：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe --version
```

后续可直接调用虚拟环境中的解释器，无需先激活环境。`.venv` 已包含在忽略规则中，不提交到 Git。

### 3. 运行第一个示例

新建 `hello.py`，写入：

```python
print("Hello, Python!")
```

然后执行：

```powershell
.\.venv\Scripts\python.exe .\hello.py
```

预期输出为 `Hello, Python!`。这里的 `hello.py` 是入门练习，需要自行创建；当前仓库尚未提供该文件。

## 练习约定

- 每个练习围绕一个知识点，优先保持示例简短、可独立运行。
- 文件名使用小写字母和下划线，例如 `read_text_file.py`。
- 注释说明关键思路和容易出错的地方，学习笔记使用中文。
- 涉及文件输入时，说明输入格式、运行命令和预期结果。
- 优先使用 Python 标准库；引入第三方库时，记录依赖和安装方式。
- 修改示例后实际运行，检查正常输入和典型异常输入。
- 不提交虚拟环境、缓存、密码或包含敏感信息的日志和固件文件。

## 学习记录

每次练习可记录以下内容，方便回顾：

1. **目标**：本次要掌握的知识点或解决的问题。
2. **实现**：代码思路、关键语法和使用的模块。
3. **验证**：运行命令、输入数据和实际输出。
4. **复盘**：遇到的问题、原因以及修正方法。
